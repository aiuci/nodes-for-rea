# 0.3.0-preview.20261027.1 — Windows x64 preview

Application-aware investigation with bounded, adaptive continuation.

- Folder intake retains application inventory and the selected objective through application selection, readiness recovery, continuation and reopening.
- Investigate adapts within its saved allowance. Continue automatically separately permits additional turns within the selected bound. Surface Pass remains a single bounded overview.
- Read attempts, provider retries and inspection operations consume cumulative allowance. Explicit additional grants add allowance; resuming preserves the remainder. Stop retains completed findings.
- Evidence-linked implementation modules are admitted only within the application folder after host identity and containment checks.
- Portable documents preserve legitimate coverage identifiers containing feature labels; opaque action/message identifiers and archive validation retain their existing restrictions.
- Includes Desktop Candidate saved evidence reading, evidence-aware map/Outline presentation and Agent Control work since the previous public package.

Validation: 945 source tests; native desktop and packaged export/open/fresh-reopen of an affected investigation with eight snapshots and nine coverage areas; seven controlled folder/selection/continuation/reopen/Surface Pass/additional-grant checks; clean local npm installation, launch/profile lock, real bundled REA JavaScript inspection, evidence/draft persistence and custom data paths.

One real folder-only application intake produced supported implementation tracing and stopped within its allowance. It did not resolve loading behavior or establish equivalent depth across applications. Controlled checks use owned fixtures and simulated reasoning; they do not establish real-provider quality. The broader integrated Agent Control camera/Save As/fresh-open acceptance gate has not achieved a complete pass; this release's export gate covers the affected document flow specifically.

Windows x64 only. AGPL-3.0-only; branding reservations unchanged. No private investigations, evidence, account settings or profiles are included.
