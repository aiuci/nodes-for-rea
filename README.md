# Nodes for REA

A persistent visual workspace for exploring applications with REA and your connected AI agent.

## Windows download

[Download the Windows preview](https://github.com/aiuci/nodes-for-rea/releases)

Under Assets, choose **Nodes-for-REA-…-Windows-x64.zip**. Extract the entire folder and run **Nodes for REA.exe**. Keep the bundled files together.

The automatic “Source code” archives are not the Windows app. Keep your previous app folder when upgrading; save investigations as .reanodes documents and reopen them through File → Open in the new build.

## Features

- Persistent mind maps, saved investigations and evidence-linked findings.
- Agent Control for planning and approving investigation directions.
- Local dictation for editable text fields; keyboard sidebar navigation.
- Readable partial drafts and recovery after interrupted work.

Connect your AI agent through Setup. Local dictation offers an optional one-time 199 MB download; typed requests work without it. See each release for requirements, validation and known issues.
