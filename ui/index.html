    Make yourself at home.

    Nodes for REA is a workspace that guides the REA inspection engine. Your agent reasons about the findings. Investigations need a working REA engine; some target types need additional REA tools.

    1. Nodes for REA

    Nodes app: running. The Windows portable edition includes its app runtime. Keep the extracted app folder together; that edition does not require a separate Node.js installation.

    Connect your AI agent

    Looking for local agents…

    Detection checks installed versions and local sign-in status. It does not request an AI response or change your account.

    Advanced connection or OpenClaw gateway

    Codex is included in the portable app. An existing Codex sign-in on this computer is reused. Otherwise, sign in with ChatGPT below.

    Existing CLI or model (optional)

    Use your installed Claude Code and its existing account. Install the current Claude Code first if needed, then reopen this panel.

    Existing CLI or model (optional)

    Your gateway must be running and its Chat Completions endpoint enabled. Use a dedicated agent with read-only tools; your gateway’s own tool permissions apply. Tokens are encrypted for this computer and must be entered again on another computer.

    Enable the OpenClaw connection
    openclaw config set gateway.http.endpoints.chatCompletions.enabled true
openclaw gateway restart

    This is a gateway setting you apply on the computer running OpenClaw. REA sends captured excerpts as structured reasoning requests.

    This optional test sends a small AI request and may use your plan or credits. A successful AI test does not establish inspection-provider readiness.

    2. REA inspection engine

    REA does the inspection. Use the engine included with this edition when available, or connect your own working REA installation. Additional decompilers and their runtimes are REA requirements for specific targets.
